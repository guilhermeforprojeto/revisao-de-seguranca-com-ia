# Prompts prontos

## Revisão completa

```text
Revise a segurança deste projeto seguindo https://github.com/guilhermeforprojeto/revisao-de-seguranca-com-ia
```

## Rápida, antes de commit ou deploy

```text
Revisão rápida de segurança seguindo https://github.com/guilhermeforprojeto/revisao-de-seguranca-com-ia : só segredos, dependências e injeção. Não instale nada.
```

## Só as mudanças de uma branch ou PR

```text
Revise a segurança só das mudanças desta branch em relação à main, seguindo https://github.com/guilhermeforprojeto/revisao-de-seguranca-com-ia
```

## Multi-tenant / SaaS

```text
Revise a segurança seguindo https://github.com/guilhermeforprojeto/revisao-de-seguranca-com-ia com foco em isolamento entre clientes: quero ter certeza de que um cliente não vê nem altera dados de outro.
```

## App com agente local ou IA

```text
Revise a segurança seguindo https://github.com/guilhermeforprojeto/revisao-de-seguranca-com-ia com foco na seção "IA, LLM e agentes" do checklist: prompt injection, permissões das ferramentas e o que o agente aceita executar.
```

## Corrigir depois do relatório

```text
Corrija as falhas Críticas e Altas do RELATORIO-SEGURANCA.md, uma por commit, com teste quando der. Depois rode as ferramentas de novo e atualize o relatório.
```
